Ejemplo: scroll horizontal por modelo de caja (content-box)

Esta página muestra un desbordamiento horizontal causado porque el elemento tiene width:100% más padding y border usando el modelo por defecto box-sizing: content-box.

Este elemento tiene width:100% dentro de un contenedor de 400px, pero además tiene padding y border; por tanto el ancho total excede los 400px y provoca un scroll horizontal.
